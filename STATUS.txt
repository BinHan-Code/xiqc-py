Date: 2026-05-10

WHAT THIS IS
------------
A Python library + CLI for the ExtremeCloud IQ Controller (XIQ-C) REST API.
Target: AP/Station/Site inventory, telemetry pipeline feed, RF ML data.
License: Apache 2.0. Repo is PUBLIC.

CURRENT STATE: Skeleton / Foundation complete
---------------------------------------------
All core plumbing is in place but NO real API endpoints are implemented yet.
Everything is typed, linted, tested — nothing is a stub that would break callers.

Files and what's done:

KEY CONSTRAINTS TO REMEMBER
----------------------------
- All HTTP goes through XiqcClient._request(). Never call httpx directly elsewhere.
- All auth goes through AuthClient. Never pass tokens inline.
- All responses must parse into pydantic models. No raw dict returns.
- CLI commands are thin: env → client → format. No business logic.
- Rate limit: ≤ 2 req/s (already enforced by _throttle in _http.py).
- TLS: default verify=True. Honour XIQC_VERIFY=false but log a warning.
- No real customer data anywhere — synthetic values only (see CLAUDE.md).
- Dependency changes need a human decision before adding.
